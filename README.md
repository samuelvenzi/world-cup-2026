# ⚽ Copa do Mundo 2026 — Álbum de Figurinhas

Ferramenta para acompanhar a sua coleção do álbum Panini da Copa do Mundo FIFA 2026.

## Funcionalidades

- **980 figurinhas** organizadas por seção e seleção (grupos A–L)
- Marca figurinhas como coletadas com um clique
- Registra figurinhas repetidas com os botões +/−
- Figurinhas foil/especiais destacadas em dourado (★)
- Abas **Faltam** e **Repetidas** para gestão da coleção
- Progresso salvo automaticamente no dispositivo (sem conta, sem servidor)
- Exportar / importar progresso como JSON
- Tema claro e escuro

## Desenvolvimento local

```bash
npm install
npm run dev
```

Abra `http://localhost:5173` no browser.

## Stack

- [React 18](https://react.dev)
- [Vite 5](https://vitejs.dev)
- Sem backend — tudo persiste no `localStorage` do browser

## Aviso

Ferramenta não oficial criada por fãs. Não afiliada à Panini ou à FIFA.
